
# Week 8 Final Project: Personal Mini-Toolkit

## What the Toolkit Does

This Python program contains three useful tools:

1. **Simple Calculator:** Adds, subtracts, multiplies, and divides two numbers.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Multiplication Table:** Displays the multiplication table of any whole number from 1 to 10.

## How to Run

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python toolkit.py
```

5. Choose a tool from the main menu.

## Reflection

The hardest part of this project was building the menu loop and making each tool work correctly. The longest bug I faced was an indentation error involving the if and elif statements. I learned how to use loops, conditionals, lists, and user input in a single Python program. The calculator helped me practise arithmetic operations. The to-do list helped me understand how lists can be changed by adding and removing items. The multiplication table helped me practise using for loops. If I had one more week, I would add a feature to save tasks in a file so they remain available after closing the program.
